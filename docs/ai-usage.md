# AI Usage Report

## Overview

AI tools were used throughout the development of **Incubyte Motors** to assist with planning, implementation, debugging, and documentation.

AI acted as a productivity tool rather than a replacement for software engineering. Every suggestion was reviewed, modified where necessary, tested, and manually integrated into the project.

---

# AI Tools Used

| Tool | Purpose |
|------|---------|
| ChatGPT | Architecture discussions, implementation guidance, debugging, documentation |
| DeepSeek | Code suggestions and problem solving |
| Official Documentation | Framework and API references |

# Responsible AI Usage

During development:

- AI suggestions were reviewed before use.
- Generated code was modified when required.
- Security-sensitive logic was manually verified.
- All features were tested before submission.
- Final architectural decisions were made by the developer.
